# Domain docs

Before exploring the codebase, read:

- `CONTEXT.md` at the repository root
- Relevant ADRs under `docs/adr/`

If these files do not exist, continue without creating them. Create domain documentation only when domain terms or architectural decisions need recording.

This repository uses a single-context layout:

/
├── CONTEXT.md
├── docs/adr/
└── src/

Use terminology defined in `CONTEXT.md`. If proposed work conflicts with an ADR, report the conflict instead of silently overriding the decision.
