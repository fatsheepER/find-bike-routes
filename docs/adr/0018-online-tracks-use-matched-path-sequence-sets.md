# 联机轨迹使用匹配路径 sequence set

MobilityDB 的 `track.trajectory` 只承载通过全部九条硬剔除的有效轨迹，并沿完整地图匹配道路构造 EPSG:32650 `tgeompoint`。道路顶点的时间按相邻匹配观测点的路径偏移线性插值；每个匹配路径片段是一个 sequence，路径断点之间保持未知，整条轨迹以 sequence set 存储。只连接原始 GPS 点或吸附点会在转弯处拉出穿过建筑的直线，而跨断点插值会把未知路径伪造成已知穿越。

## Consequences

- 导入器按有效轨迹关联轨迹时间、匹配点偏移和匹配路径片段，不入库无效轨迹。
- 源数据的本地时间按 `Asia/Shanghai` 解释为带时区时间，并单存当地 `source_date`。
- 联机查询先限制时间，再判断匹配路径与框选范围相交；断点之间不会贡献穿越。
