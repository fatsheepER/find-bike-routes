# 无区域段够去抖门槛即切断序列

去抖规则原先只处理「一次进入够不够 100 米或 2 个匹配点」。单元格没有区域时，notebook 把它当成永远不够格，并入前一次进入。12-21 上从未遇到过无区域的格子，所以这条路径没被执行过。套到 12-23，冻结划分覆盖不到的格子会出现在两次进入之间。

我们把「区域为空且自身够去抖门槛」定为**切断**：它之前的进入收尾，它之后的下一次进入以 `gap_before = true` 起头，切断两侧即使区域相同也不合并。不够门槛的无区域段仍并入前一次进入，与 notebook 一致。门槛沿用 100 米 / 2 个匹配点，不另设一个数。

在冻结区域之外骑了 300 米再回来，不是从 A「直接进入」B，不该记成相邻转移。

## Considered Options

- 一律并入前一次进入：雨天绕开冻结区域的那段会被记成 A→B 的相邻通道流。
- 任何无区域段都切断，包括只有几十米的：有覆盖无链路的格子上一次短穿越也会把序列切开，过碎。
- 另设切断门槛：答辩时要解释两个几乎相同的数。

## Consequences

- `track_regions` 多一列 `gap_before`。通道流只在 `gap_before = false` 的相邻进入之间计。
- 整段都是无区域进入时结果为空列表，不计切断。晴天集上分析几何覆盖全部有链路的格，切断只在 12-23 上触发。
- `regions` 的粒度扫描与 `assign-regions` 的 UDF 调用同一个纯函数。
