# 通道流零模型保出入强度，出行流零模型保精确双边距

计划第 7 节把「构造保持行列和的随机重排零模型」写成两张矩阵共用的一句话，落到实现上它们不能共用一个构造。出行流的记录单位是行程，随机置换行程的终点区域就让行和（各起点的行程数）与列和（终点区域的多重集）都**精确**保持，代价为零。通道流的记录单位是相邻区域转移，支撑受区域邻接约束：端点重排会造出地理上根本不存在的区域对，于是几乎每个真实对都「显著」，检验退化成在验证地理。

通道流的第一版曾定为「在观测支撑上只重排权重」，这是错的。那样每个区域对的零分布都是同一个权重多重集，`null_mean` 与 `null_sd` 对所有对相同，`z` 成为观测权重的单调函数，显著流对等于按权重排的 Top-K，BH-FDR 只是换个说法表达同一个 K，这一臂不产生任何超出「我数出来的」的信息。因此改为：在观测支撑上按两端区域的观测出入强度之积 `p_ij ∝ s_out_i · s_in_j`（归一到支撑内）对当日通道流总量做多项抽样，100 次。`z` 于是回答「这条相邻关系承载的量，是否超出它两端区域各自吞吐量所能预测的量」。

两张矩阵的零模型强度因此不同：出行流精确保持双边距，通道流只在期望上保持。不为了对称把出行流也降级成期望保持——精确保持在那一侧是免费的。

## Considered Options

- 通道流也用端点重排、但限制在该区域观测到的出邻居内：行和精确、列和期望保持，实现比强度积麻烦，信息量一样。
- 通道流用支撑内纯权重重排：退化成按权重排序，见上。
- 两张矩阵统一成期望保持以求对称：白丢掉出行流已经免费拿到的精确性。

## Consequences

- `flow_significance` 带 `null_model` 列区分两种构造；报告不得把两张矩阵的 `z` 直接放在一起比大小。
- 通道流一侧另报实测边际偏差 `mean |Σ_j w'_ij − s_out_i| / s_out_i`，说明「期望保持」在 100 次里实际偏了多少。
- 自环不参与显著性判定，对角线的 `z` 单独作自环旁证。
- ADR-0010 的链路权重零模型不受影响：那里重排之后要重跑 Infomap 再比 AMI，退化只发生在逐对 `z` 检验上。
- 两个零模型的 `null_mean` 与 `null_sd` 都有闭式（无放回抽样与多项抽样），用解析式对照 100 次蒙特卡洛，这是第 7 步唯一的独立参照，不另写参考实现。
- `CONTEXT.md` 的「零模型」词条按此定名为「支撑内强度零模型」。
