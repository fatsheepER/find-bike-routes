# 数据库是单版本只读发布副本

数据挖掘阶段的 Parquet 产物及其内容摘要继续作为唯一事实来源。MobilityDB 和预计算 GeoJSON 只发布同一冻结运行；数据库只保留一个活动版本，并在单个离线事务中整库替换。Web 应用没有写入业务或历史版本查询，让数据库反过来成为权威源、或让每张表携带 `release_id`，只会产生两套可能漂移的口径。

## Consequences

- `dataset_release` 只有一行，记录结构版本、上游分组内容摘要、冻结划分摘要与导入时间。
- 重复导入同一内容是成功的无操作；替换不同内容需要显式覆盖意图，任何失败都保留旧版。
- API 连接用户只有读权限，只有导入用户可以替换发布数据。
