# 数据库是单版本只读发布副本

数据挖掘阶段的 Parquet 产物及其内容摘要继续作为唯一事实来源。MobilityDB 只发布同一冻结运行的一个活动版本，并在单个离线事务中整库替换。Web API 直接查询这个只读发布副本，不再维护一套预计算 GeoJSON；GeoJSON 只作为空间响应格式。频繁区域序列仍从 Parquet 产物读取，并用冻结划分摘要与数据库核对。Web 应用没有写入业务或历史版本查询，让数据库反过来成为权威源、或让每张表携带 `release_id`，只会产生两套可能漂移的口径。

## Consequences

- `dataset_release` 只有一行，记录结构版本、上游分组内容摘要、冻结划分摘要与导入时间。
- 重复导入同一内容是成功的无操作；替换不同内容需要显式覆盖意图，任何失败都保留旧版。
- API 连接用户只有读权限，只有导入用户可以替换发布数据。
- 区域、片区、画像、流和轨迹请求直接读取 MobilityDB；`grid_cell` 只保留冻结划分成员关系，不为它增加产品接口。
- 只有频繁区域序列继续读取独立 Parquet 产物。健康检查拒绝冻结划分摘要不一致的组合。
